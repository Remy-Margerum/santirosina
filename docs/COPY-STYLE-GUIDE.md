# Santi Rosina — copy style guide (transcribed)

From **"Santi Rosina Style Guide - Copywriting.docx"** (Drive, *SAN - Santi Rosina / Brand Documents*). Everything the
site says follows it; `site/tests/content.test.ts` fails a build whose words use the *Don't use* list.

**Voice.** Warm, grounded, confident, Italian-spirited. The wine speaks for itself. The copy doesn't need to shout.

**Rules**
1. Show, don't sell. Describe what it is. Don't tell the reader it's exceptional.
2. One superlative per section. If you're stacking "remarkable," "exceptional," and "extraordinary," cut them. Add a
   specific detail instead.
3. Italian warmth, not French formality. Wine belongs on the table next to food and conversation, not on a pedestal.
4. Never name the owners in public-facing materials without explicit approval. Use "the family" or "a family's Italian
   roots."
5. **All copy requires Kathryn Paul's written approval before publication.**

**Word choices**

| Instead of | Use |
|---|---|
| compelling | beautiful |
| meticulous | patient |
| cultivate | grow |
| respect (for the land) | love |
| pedigree | character |
| remarkable, extraordinary | distinctive |
| extremely limited quantities | limited-production |
| represent the intersection of | reflect |

**Don't use:** rare opportunity, truly exceptional, acquire, luxury wine landscape, vertical collections, unwavering
commitment, world-class, curated, bespoke, exclusive access, unparalleled, nestled.

**The Italian thread.** The Italian identity is real (the name honors the owner's Italian parents) and runs through the
brand: the landscape, the philosophy, the varietals, the label. But it should never feel forced. The brand unites
Italian and Bordeaux varietals. The copy should reflect that duality, not pretend to be an Italian winery.

**The test.** Read it out loud. If it sounds like a press release, rewrite it. If you'd say it at a dinner table, it's
right.
